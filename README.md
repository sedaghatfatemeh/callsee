# Callsee Documentation Landing

A static RTL landing page for introducing Callsee and organizing its documentation.

## Files
- `index.html`
- `styles.css`
- `script.js`
- `assets/images/`

## GitHub Pages
1. Upload all files to a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your main branch and `/ (root)`.
5. Save.

No build step or framework is required.

## Customize
- Update copy directly in `index.html`.
- Replace screenshots in `assets/images/` and keep the same paths, or update image paths in the HTML.
- Replace the CSS variables at the top of `styles.css` to adjust brand colors.
