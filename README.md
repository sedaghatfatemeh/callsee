# Callsee Documentation Landing

صفحه معرفی و مستندات سامانه مدیریت مرکز تماس Callsee.

## اجرا
فایل `index.html` را در مرورگر باز کنید.

## انتشار روی GitHub Pages
1. همه فایل‌ها و پوشه‌ها را در ریشه Repository قرار دهید.
2. در GitHub به `Settings > Pages` بروید.
3. گزینه `Deploy from a branch` را انتخاب کنید.
4. Branch را روی `main` و Folder را روی `/ (root)` بگذارید.
5. Save را بزنید.

## ساختار
- `index.html` — صفحه اصلی
- `styles.css` — استایل‌ها
- `script.js` — تعاملات، گالری، جستجو و منوی موبایل
- `assets/images/` — تصاویر واقعی استخراج‌شده از مستندات Callsee
- `assets/docs/callsee-manual.pdf` — فایل کامل مستندات

تمام لینک‌ها Relative هستند و برای GitHub Pages مناسب‌اند.
